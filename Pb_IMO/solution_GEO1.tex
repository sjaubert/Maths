\section*{\'Enonc\'e}

$ABCD$ est un trap\`eze rectangle ($\angle B = \angle C = 90\degmark$).
$E \in [BC]$ avec $BE = 3\;\text{cm}$ et $EC = CD = x$.
Les droites $(AC)$ et $(ED)$ se coupent en $F$ avec $(AC) \perp (ED)$.
L'aire du triangle $ADF$ vaut $28\;\text{cm}^2$.
Trouver $CD$.

\section*{Solution}

\textbf{\'Etape 1 -- $F$ est le milieu de $[ED]$.}

Le triangle $ECD$ est rectangle en $C$ (car $\angle BCD = 90\degmark$)
avec $EC = CD = x$ : c'est un \textbf{triangle isoc\`ele rectangle}.
Le pied de la hauteur issue de $C$ sur l'hypot\'enuse $[ED]$
est donc le \textbf{milieu} $F$ de $[ED]$.

On v\'erifie que $F$ est aussi sur $(AC)$ :
\[
  \overrightarrow{AC} = (BC,\; -AB) \quad\text{et}\quad
  \overrightarrow{ED} = (EC,\; CD) = (x,\; x),
\]
d'o\`u\; $\overrightarrow{AC}\cdot\overrightarrow{ED} = x\cdot BC - AB\cdot x = x(BC - AB)$.
Avec $AB = BC = x + 3$, ce produit scalaire vaut $0$, confirmant $(AC)\perp(ED)$.\;\checkmark

\bigskip

\textbf{\'Etape 2 -- Lien entre les aires.}

Puisque $F$ est le milieu de $[ED]$, les triangles $ADF$ et $AEF$
ont m\^eme sommet $A$ et des bases $FD = FE = \frac{ED}{2}$ port\'ees par la m\^eme droite.
Donc~:
\[
  \text{Aire}(ADF) = \text{Aire}(AEF) = \frac{1}{2}\,\text{Aire}(ADE).
\]
D'o\`u $\;\text{Aire}(ADE) = 2 \times 28 = 56\;\text{cm}^2$.

\bigskip

\textbf{\'Etape 3 -- Calcul de l'aire de $ADE$ par soustraction.}

On d\'ecompose :
\[
  \text{Aire}(ADE) = \text{Aire}(ABCD) - \text{Aire}(ABE) - \text{Aire}(ECD).
\]

\begin{itemize}
  \item \textbf{Trap\`eze $ABCD$} (bases $AB = x{+}3$ et $CD = x$, hauteur $BC = x{+}3$)~:
    \[
      \text{Aire}(ABCD) = \frac{(AB + CD)\cdot BC}{2}
      = \frac{(2x+3)(x+3)}{2}.
    \]
  \item \textbf{Triangle $ABE$} (rectangle en $B$, $AB = x{+}3$, $BE = 3$)~:
    \[
      \text{Aire}(ABE) = \frac{(x+3)\cdot 3}{2}.
    \]
  \item \textbf{Triangle $ECD$} (rectangle isoc\`ele en $C$, $EC = CD = x$)~:
    \[
      \text{Aire}(ECD) = \frac{x^2}{2}.
    \]
\end{itemize}

Donc~:
\begin{align*}
  \text{Aire}(ADE)
  &= \frac{(2x+3)(x+3)}{2} - \frac{3(x+3)}{2} - \frac{x^2}{2} \\[6pt]
  &= \frac{(x+3)\bigl[(2x+3)-3\bigr] - x^2}{2}
  = \frac{2x(x+3) - x^2}{2}
  = \frac{x^2 + 6x}{2}.
\end{align*}

\bigskip

\textbf{\'Etape 4 -- Conclusion.}

\[
  \text{Aire}(ADF) = \frac{1}{2}\cdot\frac{x^2+6x}{2} = \frac{x^2+6x}{4} = 28
\]
\[
  x^2 + 6x - 112 = 0
  \qquad\Longrightarrow\qquad
  \Delta = 36 + 448 = 484 = 22^2
\]
\[
  \boxed{\;CD = x = \frac{-6+22}{2} = 8\;\text{cm}\;}
\]
