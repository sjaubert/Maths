\section*{\'Enonc\'e (tel que lu sur la figure)}

$ABCD$ est un trap\`eze droit ($\angle B = \angle C = 90\degmark$),
avec les c\^ot\'es parall\`eles $AB$ et $CD$ perpendiculaires \`a $BC$.
Un point $E \in [BC]$ v\'erifie $BE = 3\;\text{cm}$.
Les droites $(AC)$ et $(ED)$ se coupent en $F$ avec $(AC) \perp (ED)$.
L'aire du triangle $ADF$ vaut $28\;\text{cm}^2$.
On pose $CD = x$.

\textbf{Trouver $CD$.}

\section{Mise en \'equations g\'en\'erale}

On place un rep\`ere orthonorm\'e : $B = (0,0)$, l'axe $Bx$ le long de $[BC]$.
Avec $c = BC > 3$ et $h = AB$~:
\[
  B = (0,0),\quad C = (c,\,0),\quad D = (c,\,x),\quad A = (0,\,h),\quad E = (3,\,0).
\]
On pose aussi $u = EC = c - 3$ pour all\'eger.

\subsection*{Condition de perpendicularit\'e}

$\overrightarrow{AC} = (c,\;{-h})$ et $\overrightarrow{ED} = (u,\;x)$.
\[
  (AC)\perp(ED)
  \quad\Longleftrightarrow\quad
  cu - hx = 0
  \quad\Longleftrightarrow\quad
  \boxed{h = \frac{cu}{x}}.  \tag{$\star$}
\]

\subsection*{Coordonn\'ees de $F$}

$F$ est l'intersection de $(AC)$ et $(ED)$.
Apr\`es calcul (param\'etrisation des deux droites),
on obtient~:
\[
  F = \left(3 + \frac{u^3}{x^2+u^2},\;\; \frac{u^2\,x}{x^2+u^2}\right).
\]

\subsection*{Aire du triangle $ADF$}

Par la formule du d\'eterminant
$\text{Aire} = \tfrac{1}{2}\bigl|\det\bigl(\overrightarrow{AD},\,\overrightarrow{AF}\bigr)\bigr|$,
un calcul (d\'etaill\'e en annexe) donne~:
\[
  \boxed{\text{Aire}(ADF) = \frac{x\bigl(3x^2 + (u+3)\,u^2\bigr)}{2(x^2 + u^2)}}.
  \tag{$\star\star$}
\]

%--------------------------------------------------------------------------
\section{Le probl\`eme est sous-d\'etermin\'e}

L'\'equation $\text{Aire}(ADF) = 28$ s'\'ecrit, avec $(\star\star)$~:
\[
  x\bigl(3x^2 + (u+3)\,u^2\bigr) = 56\,(x^2 + u^2).
\]
Soit, en d\'eveloppant~:
\[
  3x^3 - 56x^2 + u^2(u+3)\,x - 56u^2 = 0.   \tag{E}
\]

C'est \textbf{une seule \'equation \`a deux inconnues} ($x = CD$ et $u = EC$).
Elle admet donc une \textbf{infinit\'e de solutions} :
pour chaque valeur de $EC$, il existe en g\'en\'eral une valeur de $CD$
qui satisfait les contraintes du probl\`eme.

La table ci-dessus confirme que \textbf{$CD$ d\'epend de $EC$}.
Le probl\`eme n'a pas de solution unique avec les seules donn\'ees
de la figure.

\medskip

\textbf{Remarque.}
La seule ligne o\`u $EC = CD$ est la ligne $u = 8$, $x = 8$.
Si l'on ajoute l'hypoth\`ese $EC = CD = x$ (not\'ee parfois sur certaines
versions de l'\'enonc\'e), l'\'equation~(E) se simplifie consid\'erablement
(voir section suivante).

%--------------------------------------------------------------------------
\section{R\'esolution avec l'hypoth\`ese $EC = CD$}

On pose $u = x$ (c'est-\`a-dire $EC = CD$), d'o\`u $c = x + 3$.
L'\'equation~(E) devient~:
\begin{align*}
  3x^3 - 56x^2 + x^2(x+3)\,x - 56x^2 &= 0 \\
  x^2\bigl[3x - 56 + (x+3)x - 56\bigr] &= 0 \quad\text{(factorisation par $x^2$)}\\
  x^2\bigl[x^2 + 6x - 112\bigr] &= 0.
\end{align*}

Comme $x > 0$, on r\'esout $x^2 + 6x - 112 = 0$~:
\[
  \Delta = 36 + 448 = 484 = 22^2
  \qquad\Longrightarrow\qquad
  x = \frac{-6 + 22}{2} = 8.
\]

\[
  \boxed{\;CD = 8\;\text{cm}\;}
\]

Le trap\`eze a alors pour dimensions :
$AB = BC = 11\;\text{cm}$,\; $CD = 8\;\text{cm}$,\; $EC = 8\;\text{cm}$.

\bigskip
\textbf{V\'erification.}
$A = (0,11)$, $D = (11,8)$, $F = (7,4)$.
\begin{itemize}
  \item $\overrightarrow{AC}\cdot\overrightarrow{ED}
    = (11)(8) + (-11)(8) = 0$.\;\checkmark
  \item $F$ milieu de $[ED]$ : $\tfrac{1}{2}(3+11, 0+8) = (7,4)$.\;\checkmark
  \item Aire$(ADF)
    = \tfrac{1}{2}|11(4-11) - 7(8-11)|
    = \tfrac{1}{2}|{-77+21}| = 28$.\;\checkmark
\end{itemize}

%--------------------------------------------------------------------------
\section*{Annexe -- D\'etail du calcul de l'aire}

$A = (0,\,h)$, $D = (c,\,x)$, $F = \bigl(\frac{3x^2+cu^2}{x^2+u^2},\;\frac{u^2 x}{x^2+u^2}\bigr)$
o\`u $h = cu/x$.

\[
  \text{Aire} = \frac{1}{2}\bigl|
  \underbrace{(x_D - x_A)}_{c}(y_F - y_A) - (x_F - x_A)(y_D - y_A)\bigr|
\]

\begin{align*}
  y_F - y_A &= \frac{u^2 x}{x^2+u^2} - \frac{cu}{x}
  = \frac{u^2 x^2 - cu(x^2+u^2)}{x(x^2+u^2)}
  = \frac{-u(3x^2 + cu^2)}{x(x^2+u^2)}
\end{align*}
\begin{align*}
  x_F - x_A &= \frac{3x^2 + cu^2}{x^2+u^2},\qquad
  y_D - y_A = x - \frac{cu}{x} = \frac{x^2 - cu}{x}
\end{align*}

Apr\`es simplification du d\'eterminant (on factorise $(3x^2+cu^2)$
qui appara\^it dans les deux termes), on arrive \`a~:
\[
  \text{Aire}(ADF) = \frac{x(3x^2 + cu^2)}{2(x^2+u^2)}.
\]
