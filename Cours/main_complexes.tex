\section{Introduction : Pourquoi les nombres complexes en ingénierie ?}
% ==========================================

Dans l'ensemble des nombres réels ($\mathbb{R}$), le carré d'un nombre est toujours positif ou nul. Par conséquent, une équation simple comme $x^2 + 1 = 0$ (soit $x^2 = -1$) n'a \textbf{aucune solution}.
Pour dépasser cette limite, les mathématiciens ont imaginé un nombre dont le carré serait égal à $-1$. En mathématiques pures, ces nombres complexes ont été créés pour résoudre des équations polynomiales.

Cependant, dans le milieu industriel, leur utilité est redoutable pour une tout autre raison : \textbf{la résolution d'équations différentielles en régime sinusoïdal}. Que ce soit le courant électrique dans un moteur asynchrone, ou les vibrations mécaniques d'une ligne d'usinage, la majorité des phénomènes industriels impliquent des ondes de forme sinusoïdale.

\begin{attention}[La convention industrielle du ``j'']
En mathématiques pures, le nombre imaginaire fondamental est noté $i$ (tel que $i^2 = -1$). Cependant, en \textbf{électrotechnique et en électronique}, la lettre $i$ désigne déjà l'intensité du courant variable $i(t)$. Pour éviter toute confusion tragique dans vos calculs, \textbf{nous utiliserons systématiquement la lettre $\jc$} (j comme "jmaginaire") dans ce cours.
\end{attention}

On définit donc le nombre complexe $\jc$ tel que :
\begin{center}
    \Large $\jc^2 = -1$
\end{center}
L'ensemble de tous les nombres complexes est noté $\mathbb{C}$.

\section{Fondations Mathématiques : Algèbre et Géométrie}
% ==========================================

Un nombre complexe $\cpx{z}$ peut être perçu comme un "vecteur" dans un plan à deux dimensions composé d'un axe réel et d'un axe imaginaire.

\subsection{La forme algébrique : Composantes cartésiennes}
\begin{vocabulaire}[Définition de la forme algébrique]
Tout nombre complexe $\cpx{z}$ s'écrit de manière unique sous la forme algébrique :
$$\cpx{z} = a + \jc b$$
Où $a$ et $b$ sont des nombres réels.
\begin{itemize}
    \item $a$ est la \textbf{partie réelle} de $\cpx{z}$, notée $\text{Re}(\cpx{z})$. (Par ex. la "Résistance" pure).
    \item $b$ est la \textbf{partie imaginaire} de $\cpx{z}$, notée $\text{Im}(\cpx{z})$. (Par ex. la "Réactance").
\end{itemize}
\end{vocabulaire}

\textbf{Opérations de base :} Les règles de calcul (addition, multiplication) sont les mêmes que pour les réels, en se rappelant toujours que $\jc^2 = -1$.
\begin{itemize}
    \item \textbf{Addition :} on additionne les réels entre eux, et les imaginaires entre eux. \\
    $(2 + 3\jc) + (4 - \jc) = (2+4) + (3-1)\jc = 6 + 2\jc$
    \item \textbf{Multiplication :} on développe de façon classique. \\
    $(2 + \jc)(3 - 2\jc) = 6 - 4\jc + 3\jc - 2\jc^2 = 6 - \jc - 2(-1) = 8 - \jc$
\end{itemize}

\textbf{Le conjugué et la division :}
Pour diviser, on utilise le \textbf{conjugué}. Le conjugué d'un nombre $\cpx{z} = a + \jc b$ est noté $\bar{z} = a - \jc b$.
Propriété : $\cpx{z} \times \bar{z} = (a + \jc b)(a - \jc b) = a^2 - (\jc b)^2 = a^2 + b^2$. Le résultat devient un réel pur !

\begin{exemple}[Calcul d'une admittance]
En électricité, l'admittance $\cpx{Y}$ est l'inverse de l'impédance $\cpx{Z}$. Si $\cpx{Z} = 3 + 4\jc\ \Omega$ :
$$\cpx{Y} = \frac{1}{\cpx{Z}} = \frac{1}{3 + 4\jc}$$
Pour écrire ce résultat sous forme algébrique, on multiplie en haut et en bas par le conjugué du dénominateur ($3 - 4\jc$) :
$$\cpx{Y} = \frac{1 \times (3 - 4\jc)}{(3 + 4\jc)(3 - 4\jc)} = \frac{3 - 4\jc}{3^2 + 4^2} = \frac{3 - 4\jc}{25} = 0,12 - \jc 0,16 \text{ Siemens}$$
\end{exemple}

\subsection{Représentation géométrique : Le plan complexe}
Tout comme un réel représente un point sur une droite, un nombre complexe $\cpx{z} = a + \jc b$ représente un point $M$ de coordonnées $(a, b)$ dans un plan muni d'un repère orthonormé. C'est la base de la représentation de \textbf{Fresnel} en électrotechnique.

\end{tikzpicture}
\end{center}

\subsection{Formes trigonométrique et exponentielle}
Plutôt que des coordonnées (x,y), il est souvent plus pertinent de décrire le vecteur par sa distance et son angle.

\begin{vocabulaire}[Module et Argument]
Pour un nombre complexe $\cpx{z} = a + \jc b$ associé au point $M$ :
\begin{itemize}
    \item Le \textbf{module} (noté $|\cpx{z}|$ ou $\rho$) est la distance $OM$ : $\rho = \sqrt{a^2 + b^2}$. (En industrie : l'amplitude ou la valeur efficace).
    \item L'\textbf{argument} (noté $\theta$ ou $\arg(\cpx{z})$) est l'angle orienté : $\cos(\theta) = \frac{a}{\rho}$ et $\sin(\theta) = \frac{b}{\rho}$. (En industrie : le déphasage).
\end{itemize}
\end{vocabulaire}

On aboutit alors à la forme la plus utilisée en calcul de phaseurs grâce à Euler :
\begin{center}
    \Large $\cpx{z} = \rho \left( \cos\theta + \jc \sin\theta \right) = \rho e^{\jc \theta}$
\end{center}

\textbf{Rappels des opérations sur la forme exponentielle :}
\begin{itemize}
    \item \textbf{Multiplication :} Les amplitudes se multiplient, les phases s'additionnent. \\ $\rho_1 e^{\jc \theta_1} \times \rho_2 e^{\jc \theta_2} = (\rho_1 \rho_2) e^{\jc (\theta_1 + \theta_2)}$
    \item \textbf{Dérivation temporelle :} Pour un signal $\cpx{z}(t) = Z e^{\jc \omega t}$, sa dérivée est $\deriv{\cpx{z}}{t} = \jc \omega \cpx{z}(t)$. \textit{Dériver revient simplement à multiplier par $\jc\omega$ !}
\end{itemize}

\begin{exemple}[Conversion pour un signal électrique]
Soit une tension modélisée par le complexe $\cpx{U} = 100 + \jc 100\sqrt{3}$.
\begin{itemize}
    \item Valeur efficace (Module) : $U = \sqrt{100^2 + (100\sqrt{3})^2} = \sqrt{10000 + 30000} = \sqrt{40000} = 200\text{ V}$.
    \item Déphasage (Argument) : $\cos(\theta) = \frac{100}{200} = 0,5$ et $\sin(\theta) = \frac{100\sqrt{3}}{200} = \frac{\sqrt{3}}{2}$. Donc $\theta = \frac{\pi}{3}\text{ rad}$ ($60^\circ$).
\end{itemize}
La forme exponentielle est donc : $\cpx{U} = 200 e^{\jc \frac{\pi}{3}}$.
\end{exemple}

\section{Application I : L'Électrotechnique et l'Électronique}
% ==========================================

Travailler avec des fonctions sinusoïdales du temps $i(t) = I_{max} \cos(\omega t + \varphi)$ est mathématiquement lourd. L'astuce des ingénieurs est d'associer à chaque signal son \textbf{complexe associé} (le phaseur) $\cpx{I} = I e^{\jc\varphi}$.

\subsection{Diagrammes de Fresnel}
Le diagramme de Fresnel permet de visualiser les déphasages sous forme vectorielle, ce qui est très utile pour anticiper le comportement des moteurs et des compensateurs de charge.

\subsection{L'Impédance Complexe ($\cpx{Z}$)}
La loi d'Ohm $U=RI$ se généralise au régime alternatif temporel en introduisant l'impédance complexe :
\begin{center}
    \Large $\cpx{U} = \cpx{Z} \times \cpx{I}$
\end{center}

\begin{center}
\renewcommand{\arraystretch}{1.5}
\begin{tabularx}{0.8\textwidth}{|>{\hsize=1.2\hsize}X|>{\hsize=0.8\hsize}X|>{\hsize=1\hsize}X|}
\hline
\rowcolor{uimmblue!20}
\textbf{Composant} & \textbf{Équation diff.} & \textbf{Impédance complexe $\cpx{Z}$} \\
\hline
Résistance $R$ & $u(t) = R \cdot i(t)$ & $\cpx{Z}_R = R$ \\

\hline
\end{tabularx}
\end{center}

L'impédance totale équivalente en série s'additionne simplement :
\[ \cpx{Z}_{eq} = R + \jc L\omega - \jc \frac{1}{C\omega} = R + \jc\left(L\omega - \frac{1}{C\omega}\right) \]

\subsection{Problématique Industrielle : La Puissance Complexe $\cpx{S}$}
Enedis ou votre fournisseur d'électricité facture en partie l'énergie réactive. Le bilan de puissance est calculé en complexes !
\[ \cpx{S} = \cpx{U} \cdot \bar{I} = P + \jc Q \]
\begin{itemize}
    \item $P$ est la \textbf{Puissance Active} (en Watts, utile pour générer un mouvement).
    \item $Q$ est la \textbf{Puissance Réactive} (en VAR, nécessaire pour magnétiser les bobines).
    \item $|\cpx{S}|$ est la \textbf{Puissance Apparente} (en VA, déterminant la taille du câble et du transformateur).
\end{itemize}

\section{Application II : Analyse Vibratoire et Modélisation}
% ==========================================

La mécanique vibratoire s'appuie totalement sur les nombres complexes pour analyser le comportement d'une machine tournante mal équilibrée ou la suspension d'un moteur et résoudre les oscillations contraintes.

\begin{center}
\begin{tikzpicture}
    % Mur et fixation
    \fill [pattern = north east lines] (0,3) rectangle (3,3.3);
    \draw[thick] (0,3) -- (3,3);
    % Ligne de suspension
    \draw[thick] (0.8,3) -- (0.8,2.5);
    \draw[thick] (2.2,3) -- (2.2,2.5);
    % Ressort (k) - gauche
    \draw[decoration={aspect=0.3, segment length=3mm, amplitude=3mm,coil},decorate] (0.8,2.5) -- (0.8,1);
    \node at (0.3, 1.7) {$k$};
    % Amortisseur (c) - droite
    \draw (2.0,2.5) -- (2.0,1.75);
    \draw[thick] (1.8,1.75) -- (2.2,1.75);
    \draw[thick] (1.8,1.75) -- (1.8,1.25);
    \draw[thick] (2.2,1.75) -- (2.2,1.25);
    \draw (2.0,1) -- (2.0,1.5);
    \draw[thick] (1.9,1.5) -- (2.1,1.5);
    \node at (3.2, 1.7) {Amortisseur $c$};
    % Masse (m)
    \draw[fill=blue!20, thick] (0.5,0) rectangle (2.5,1);
    \node at (1.5,0.5) {Masse $m$};
    % Force d'excitation
    \draw[->, thick, red] (1.5,0) -- (1.5,-1) node[right] {Force $F(t) = F_0 \cos(\omega t)$};
\end{tikzpicture}
\end{center}

L'équation du mouvement d'une suspension industrielle donne :
\[ m \frac{d^2x}{dt^2} + c \frac{dx}{dt} + k x = F(t) \]
En passant en notation complexe, où la position devient $x(t) \Rightarrow \cpx{X}e^{\jc\omega t}$ :
\[ (-m\omega^2 + \jc c\omega + k)\cpx{X} = F_0 \]
On extrait directement l'\textbf{amplitude complexe de vibration} : $\cpx{X} = \frac{F_0}{(k - m\omega^2) + \jc c\omega}$.

On y voit le problème phare de l'ingénierie mécanique : le point de résonance ! Si $\omega^2 = \frac{k}{m}$, la partie réelle s'annule, et seule la partie imaginaire (l'amortisseur) limite la casse de la machine.

    \item Calculer le courant efficace $I$ absorbé par le montage.
    \item Si la tension est la référence de phase ($\cpx{U} = 230 e^{\jc 0}$), quelle est l'expression complexe de $\cpx{I}$ ? Tracez rapidement l'allure du diagramme de Fresnel.
\end{enumerate}
\end{tcolorbox}

\begin{tcolorbox}[colback=green!5!white, colframe=green!60!black, title=\textbf{Exercice 5 : Analyse Vibratoire Simple}]

    \item Calculez l'amplitude du déplacement vibratoire $|X| = \frac{F_0}{|\cpx{K_{dyn}}|}$.
\end{enumerate}
\end{tcolorbox}

\section{Corrigés}
% ==========================================

\textbf{Correction - Exercice 1}
\begin{enumerate}
    \item $A = (3 - 2\jc) + (1 + 4\jc) = 4 + 2\jc$
    \item $B = (3 - 2\jc)(1 + 4\jc) = 3 + 12\jc - 2\jc - 8\jc^2 = 3 + 10\jc + 8 = 11 + 10\jc$
    \item $C = \frac{3 - 2\jc}{1 + 4\jc} = \frac{(3 - 2\jc)(1 - 4\jc)}{(1 + 4\jc)(1 - 4\jc)} = \frac{3 - 12\jc - 2\jc + 8\jc^2}{1^2 + 4^2} = \frac{3 - 14\jc - 8}{17} = -\frac{5}{17} - \jc \frac{14}{17}$
\end{enumerate}

\vspace{0.5cm}
\textbf{Correction - Exercice 2}
\begin{enumerate}
    \item Pour $z_3 = 1 + \jc$ : $\rho = \sqrt{1^2 + 1^2} = \sqrt{2}$. $\arg(z_3) = \theta$ tel que $\cos\theta = 1/\sqrt{2}$ et $\sin\theta = 1/\sqrt{2}$, d'où $\theta = \frac{\pi}{4}$. Résultat : $z_3 = \sqrt{2} e^{\jc \pi/4}$.
    \item Pour $z_4 = \sqrt{3} - \jc$ : $\rho = \sqrt{3 + (-1)^2} = \sqrt{4} = 2$. $\arg(z_4) = \theta$ tel que $\cos\theta = \sqrt{3}/2$ et $\sin\theta = -1/2$, d'où $\theta = -\frac{\pi}{6}$. Résultat : $z_4 = 2 e^{-\jc \pi/6}$.
\end{enumerate}

\vspace{0.5cm}
\textbf{Correction - Exercice 3}
L'équation est $r^2 + 2r + 5 = 0$. Le discriminant est $\Delta = 2^2 - 4(1)(5) = 4 - 20 = -16$.
Puisque $\Delta < 0$, il y a deux racines complexes conjuguées. On peut écrire $-16 = (4\jc)^2$.
Les racines sont $r_1 = \frac{-2 - 4\jc}{2} = -1 - 2\jc$ et $r_2 = \frac{-2 + 4\jc}{2} = -1 + 2\jc$.

\vspace{0.5cm}
\textbf{Correction - Exercice 4}
\begin{enumerate}
    \item $\cpx{Z_R} = 15\ \Omega$ et $\cpx{Z_L} = \jc L\omega = \jc \times 0,0477 \times 314 \approx 15\jc\ \Omega$.
    \item En série, on additionne : $\cpx{Z} = 15 + 15\jc\ \Omega$.
    \item Module : $Z = \sqrt{15^2 + 15^2} = \sqrt{450} = 15\sqrt{2} \approx 21,21\ \Omega$. Déphasage $\varphi = \arctan(\frac{15}{15}) = 45^\circ$ ou $\frac{\pi}{4}\ \text{rad}$.
    \item Loi d'Ohm en module : $I = \frac{U}{Z} = \frac{230}{21,21} \approx 10,84\ \text{A}$.
    \item Courant complexe : $\cpx{I} = \frac{\cpx{U}}{\cpx{Z}} = \frac{230 e^{\jc 0}}{21,21 e^{\jc \pi/4}} = 10,84 e^{-\jc \pi/4}$. Dans le graphe, $\cpx{U}$ est horizontal et $\cpx{I}$ pointe vers le bas à un angle de $-45^\circ$ (courant en retard en raison de l'inductance).
\end{enumerate}
